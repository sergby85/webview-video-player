# Web Video Player

Универсальная Android-обёртка над любым сайтом с видео.

## Как работает
1. При первом запуске приложение просит ввести URL сайта (например, `https://example.com`).
2. Сайт открывается в WebView, логин/пароль сохраняются (cookies).
3. При переходе по ссылке на видеофайл (`.m3u8`, `.mp4`, `.mkv`, `.avi`, `.webm`, `.ts` или URL с `/video/`) — Android показывает системный выбор плеера (VLC, MX Player и др.).
4. Кнопка «Назад» возвращает по истории WebView.

## Сборка APK (через GitHub Actions)
1. Загрузи папку `webview-video-player` в новый репозиторий на GitHub.
2. Вкладка **Actions** → workflow **Build APK** соберёт APK автоматически.
3. Скачай артефакт `webview-video-player-apk` → внутри `app-debug.apk`.

## Сборка локально
1. Установи Android Studio.
2. Открой проект → Build → Build APK(s).

## Установка на Android
1. Скопируй APK на телефон.
2. Разреши установку из неизвестных источников.
3. Установи и запусти. Введи URL нужного сайта.

## Примечания
- Приложение — обёртка, интернет обязателен.
- minSdk 24 (Android 7.0+). Huawei-совместимо (без Google Play Services).
